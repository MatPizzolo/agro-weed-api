# weedApi

Clasificador de malezas (DeepWeeds, 8 especies) servido como API + web mobile: sacás una foto y te dice qué maleza es.

## Qué demuestra

Computer vision aplicada + MLOps real (MLflow, Docker, FastAPI, deploy).

## Conexión con el dominio

Es el corazón técnico de la pulverización selectiva (lo que hace DeepAgro con SprAI).

> En las conversaciones: "esto mismo, cuantizado en una Jetson arriba del botalón, es un producto".

## Tiempo

Días 1-9 del plan que ya tenés.

## Wow factor en el stand

Que la otra persona lo pruebe en SU celular con una foto de una planta ahí mismo.
